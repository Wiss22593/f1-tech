# Espacio 3D

Esta carpeta concentra escenas, materiales, controles y utilidades de React Three Fiber.
Mantener los modelos y las texturas con licencia fuera del repositorio hasta que su uso esté verificado.

El Garage no representa coches genéricos. `assets.ts` define el contrato `F1TechCarAsset` y el registry vacío; `ModelViewer.tsx` solo carga assets registrados explícitamente. El futuro asset debe ser ORIGINAL de F1 TECH y residir en `/public/models`.
